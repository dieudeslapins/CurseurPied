Curseurs PIED chair (Grok) - 144x144 (150% de 96x96) - point chaud selon l'action

PROGRAMME : EquipeCurseurPied.exe (icone pied integree)
Double-clique dessus, puis choisis :
- Appliquer TOUS les curseurs PIED
- Restaurer TOUS les curseurs Windows
- Cycle automatique 5 s (PIED / Windows)
- Appliquer le curseur PIED principal
- Taille Windows : 48 px (cliquer pour changer) -> cycle 32 / 48 / 64 / 96 / 128 px
- Lancer avec Windows (case a cocher)

IMPORTANT : la taille VISUELLE depend du reglage Windows
HKCU\Control Panel\Cursors\CursorBaseSize (valeur par defaut 32 px).
Agrandir les fichiers .cur ne suffit pas : Windows les redimensionne a cette
valeur. Le bouton "Taille Windows" change directement ce reglage (actuellement 80 px).
Code source : EquipeCurseurPied.cs
Icone : EquipeCurseurPied.ico (7 tailles, de 16 a 256 px)

APERCU PORTABLE : ApercuCurseur.exe
- choisir un etat de curseur dans la liste (15 curseurs + entree "GIF attente
  sans jambes (30 images)"), apercu anime et zoom
- le GIF nettoye est integre dans l'EXE et s'anime dans l'apercu ; la vitesse
  des animations .ani est convertie correctement (jiffies -> ms)
- cliquer sur l'image pour placer le point chaud (hit box du clic)
- bouton "Reset point chaud" pour revenir au reglage d'origine
- case "Voir aussi comme vrai curseur" : le curseur de la souris utilise alors
  le point chaud choisi
- aucun fichier ecrit, aucun registre modifie : supprimer l'EXE suffit
- le curseur "Stylo" (nwpen.cur) est une copie du curseur Texte (ibeam.cur)

Image source : 5x3-grid-of-15.jpg (grille 5 colonnes x 3 lignes generatee par Grok).
Le fond damier gris/blanc a ete converti en transparence, puis les 15 cases
ont ete extraites en conservant leurs couleurs chair d'origine (rose clair),
puis agrandies a 150% (64 -> 96 -> 144) pour donner des curseurs Windows 144x144.

Les 15 curseurs sont dans le dossier curseurs/ (ordre de lecture de la grille) :
  1 arrow.cur         Selection normale      <- image keep-the-exact-same.jpg
  2 appstarting.ani   Traitement en arriere-plan (anime, 4 images) <- Sans titre.gif (pieds sans jambes)
  3 crosshair.cur     Precision
  4 hand.cur          Selection de lien      <- image keep-the-exact-same.jpg
  5 help.cur          Aide
  6 ibeam.cur         Texte (stylo tenu par un pied, point chaud a la pointe) <- Gemini_Generated_Image_sejxepsejxepsejx.jpg
  7 no.cur            Interdit
  8 nwpen.cur         Stylo = Texte (copie de ibeam.cur)
  9 sizeall.cur       Deplacement 4 directions <- image keep-the-exact-same.jpg
 10 sizenesw.cur      Redimension diagonale NE-SO
 11 sizens.cur        Redimension vertical
 12 sizenwse.cur      Redimension diagonale NO-SE
 13 sizewe.cur        Redimension horizontal
 14 uparrow.cur       Fleche haut
 15 wait.ani          Occupe (anime, 4 images) <- Sans titre.gif (pieds sans jambes)
Les apercus PNG sont dans curseurs/previews/ (arrow.png ... wait.png).
grok_grid_alpha.png est la grille complete apres extraction du fond.

4 curseurs (Selection normale, Traitement en arriere-plan en cours, Deplacer,
Selection de lien) utilisent l'image keep-the-exact-same.jpg : meme stylo tenu
par un pied, couleurs chair d'origine conservees, 144x144, point chaud designe
par l'utilisateur : image source keep-the-exact-same.jpg, point (162,219)
-> hotspot (28,5) (gros orteil).

Les curseurs ANIMES (appstarting.ani = traitement en arriere-plan, wait.ani =
occupe) utilisent le GIF "Sans titre.gif" (30 frames, 360x640). Seule la zone
des pieds est gardee : decoupe finale x=25..335, y=170..340, juste avant la
separation des jambes (vers y=345). Les jambes sont donc supprimees.
Le fichier attente_sans_jambes.gif contient le GIF source nettoye (30 frames,
meme decoupe, fond et jambes transparents, sans jambes) et s'affiche dans
ApercuCurseur.exe. Le masque garde tout le pied, y compris les bords clairs :
separation fond/pied sur R-G > 10 (le fond gris a R-G=6, le pied a R-G=47).
4 frames sont extraites (0, 10, 20, 29), fond rendu transparent, couleurs chair
d'origine conservees, hotspot au centre des pieds (77,80).

Le curseur TEXTE (ibeam.cur) utilise l'image
Gemini_Generated_Image_sejxepsejxepsejx.jpg, point choisi par l'utilisateur
(159,1110) -> hotspot (33,138), couleurs chair (216,190,179).

curseur.log contient l'historique des applications (diagnostic).
